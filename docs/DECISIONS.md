## 2026-09-06 — User clarifies reconstruction with evaluated adaptation

The user defines the production flow as selecting a high-scoring design website, reconstructing it, adjusting selected content or technology (explicitly including realtime 3D replaced by static imagery), assessing the adjusted webpage under the same criteria used for the source website, and delivering a new downloadable design template.

This supersedes the blanket requirement to reproduce every interaction category and the rule that an unreproduced technical behavior automatically rejects a mother. The mother remains the visual baseline; original/licensed media, identity substitution and independent implementation remain required. Technical simplifications and their necessary local layout/transition adjustments are permitted when documented and verified. They are not permission to invent unrelated sections or ignore the accepted visual baseline.

Execution improvement: identify adjustments before implementation and prototype the highest-risk substitution first, together with its adjacent transitions. Then directly build the intended adapted version. Do not build an expensive exact 3D implementation only to discard it for a static image. The complete cover/middle/transition/ending gate still precedes full-page implementation. Evaluate the final whole page after all adjustments.

The source and result use the same versioned webpage-quality rubric, at matching viewports and comparable input states. Preserve the existing 30/25/20/10/10/5 weights; define the first dimension as composition and design language (instead of similarity to a mother), and the last as webpage usability (without packaging). Fidelity becomes a separate source-counterpart and adaptation-traceability gate; source ZIP validation remains a separate binary delivery gate. Mother admission remains 98+, release 97+, every principal state 95+, ending within two points of hero, zero critical defects. Existing historical scores and Design 001 acceptance are not recalculated or relabelled as scores from this new rubric.

A static replacement receives no automatic penalty for lacking WebGL, and no automatic pass for looking similar in one screenshot. Score its actual visual authority, spatial hierarchy, interaction usefulness, continuity and responsive behavior. If the prototype cannot meet the floor, change the replacement once within a bounded experiment or reject the candidate before full implementation. This policy change does not revive the rejected Design 002 build; it permits suitable replacement mothers with verified simplifications.

## 2026-08-30 — Reconstruction-only product policy confirmed

The user confirmed that WebArt is not a self-directed design studio. Its industrial advantage comes from screening exceptional existing websites and reconstructing the smallest coherent excerpt with minimal substitution. Self-authored layout, decoration, interaction and transition work increases token use, creates inconsistent quality and causes avoidable revision.

Decision: the mother reference owns every visible design decision—composition, proportions, density, state order, transitions, fixed interface and interaction category. Original work is restricted to replacement identity, concise copy, distributable assets, independent code, responsive accommodation, accessibility and performance. Every visible element requires an observed counterpart. If a state, transition or technically essential behavior is missing or impractical to reproduce, reject the mother before implementation rather than designing a solution.
