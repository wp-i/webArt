2026-10-10核验官方GPT-6.1 Sol标准价格：每百万未缓存输入$2、缓存输入$0.10、缓存写入$2.50、输出$10；Fast文字价格为标准的2倍，272K以上请求另加价。本轮缓存写入记录为0，输出中的思考Token不再次计费。[官方模型价格](https://developers.openai.com/api/docs/models/gpt-6.1-sol)

公式：`[(输入−缓存)×2 + 缓存×0.10 + 输出×10] / 1,000,000`。若改用Fast，文字加假设图像输出费分别约$5.92/$2.47/$3.20。实际Codex服务等级未取得，不能声称已按这一价格扣费。

内置图片工具没有返回实际图像模型/质量/usage。上表仅用“GPT Image 2 high、1536×1024或1024×1536、每张输出$0.165”作替代预算，不能把假设变成实际图片账单。未含图片提示输入、搜索服务、基础设施等额外费用。[官方图像费用表](https://developers.openai.com/api/docs/guides/image-generation)

**缓存依赖明显。** 同样Token全部不命中缓存，文字加相同假设图片输出费会变为006约$18.06、007约$13.26、008约$11.92。它不是未来必然成本，而是说明当前低价依赖历史上下文缓存；未来按本页合同缩短输入、逐响应记录usage，才能形成可信报价。

LLM负责候选判断、参考拆解、素材提示、文案、HTML/CSS和视觉审核；图片也由生成模型完成。浏览器测量、源码指纹、打包和构建由确定性工具执行，仍由Codex编排。没有可支持“介入占比百分之多少”的独立测量，不用代码行数冒充占比。本轮也不是已经存在的无人值守一键执行器。
