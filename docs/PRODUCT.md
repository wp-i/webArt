# WebArt 产品约定

文档职责：产品范围按本文件的稳定约定理解，制作方式以 [生产流程](PRODUCTION_PIPELINE.md) 和 [自动化边界](production/AUTOMATION_IMPLEMENTATION.md) 的现行合同为准。下方日期、编号、数量及 Key 状态保留为阶段快照；当前任务从 [NEXT_STEPS](NEXT_STEPS.md) 定位到实际配置与收据，不据旧快照重开制作、发布或清理。

更新2026-10-14。核心目标：**配置与脚本驱动的高质量网页生产，尽量降低LLM自主执行占比。** 母版、素材、内容、关键状态和检查期待先锁定；常规生产实例化已完整准入的版本化整页渲染器，模型负责校准与证据视觉审查，不每轮生成或修补页面源码。新风格首次制作另走参考、试片和完整准入流程。品质优先，允许必要局部3D，不以易复刻删去核心。用户对001的认可仍是品质基准。

|使用路径|当前真实状态|
|---|---|
|作品目录与下载|根首页展示001/006及用户本次授权的007/008试作；2026-10-11移除整个探索/搜索/排序行，保留完整预览、屏幕尺寸切换及唯一源码下载|

001视觉冻结，原HTML迁至独立预览路径但归档内容/源码指纹保持不变。002–005废弃工程、包和重复素材已清理；旧归档23个只读Git文件被审批阻止，见[清理记录](qa/2026-10-10-cleanup.md)。用户最新审查已指出006–008文案过重、交互不足和素材质量差距，旧内部评分不证明已达到用户目标；本次用户明确要求展示全部保留稿，准许目录预览及唯一包下载，内部继续draft/trial；按用户最新要求移除试作展示标签，展示编号连续1–4。内部评分与本次展示授权都不替代视觉验收。

普通HTML/CSS、少量图片/字体和原生输入可交付短页。默认状态必须展示用途、服务/作品证据与行动；不能用装饰、隐藏正文、假控件、技术测试或单张漂亮首图代替完整设计。每段有不同作用，每图只用一次；不拼母版、不填充长度、不为复杂参考做降级替身。每件一个Vite源码ZIP，无框架/静态变体。

常规公开库存只允许完整视觉批准、QA、指纹、包验证后的条目。本次007/008的展示范围变更依据明确用户请求，独立记录在webart.showcase.json；不会自动提升为accepted。任务失败、超时、人工/模型介入、素材重生成、质量不达标均计入评测。现有两次约30分钟制作仅证明速度改善，未证明稳定95或工业量产。
