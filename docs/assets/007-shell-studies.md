# 007 / Shell studies 素材角色准备

2026-11-01当前状态：实际参考门已通过，允许按锁定角色取得素材和私有试片；`rightsVerified=false`、`replacementCompared=false`保持。目录/原作者预览与许可研究见`007-helmet-mature-source-check-20261031.json`。正核查XQCAD全罩模型实际下载与文件，尚无最终模型/PBR、人物摄影或素材模块准入；不能把参考通过或目录许可字段当作实际文件及视觉通过。

| 角色 | 必须实际证明 | 获取与许可边界 |
|---|---|---|
| 主体人物与服装 | 同一虚构设计者在正面、工作现场、侧面和佩戴收束中保持面部、发型、衣着和尺度；剪裁边缘与光线完整 | 先查有明确模板分发许可的成套摄影；只有关键同人构图无法取得时限定生成，不使用Lando肖像或服装纹样 |
| 全罩头盔与壳层 | 外壳、反光护目镜、下颌及内表面可信；在人物前的比例/位置可辨；真实输入显隐仍有厚度和工艺 | 成熟CC0/CC BY模型优先。XQCAD线索须在参考门后核查实际文件、PBR、UV、隐藏面和归属；未核验前不准入 |
| 四件表面作品及对应影像 | 每件有具体设计内容与表面差别，桌面切换至其制作/佩戴状态；手机默认完整并有明确查看方式 | 不复制源16件作品、贴图或图库；仅换颜色、重复同张照片和随机不相关头盔不能填满集合 |
| 署名、字体、地形线条 | 字形与人物/影像比例相称，签名字标与工作室身份一致，纹样有独立来源 | 优先已核验OFL字体与原创矢量，逐文件登记许可和SHA；不用源字体、签名、车队和路线图 |
| 环境、静态替代与最终渲染 | 同人同盔一致，正常/手机/故障替代仍是完整作品；静止停绘下有完成构图 | 许可覆盖模型、PBR、环境各自源码分发；最终渲染与真人贴合先做有限素材试片，不把可加载等同可采用 |

FlightHelmet当前模型文件为CC0，但皮革帽/护目镜角色不同；DamagedHelmet的官方记录保留早期非商业条款；Hikaru模型的牙齿画稿还有独立作者许可缺口。它们都没有在此采用或清权，不以常见示例模型或目录标签替代具体核验。

素材角色不以LLM创建人物头模、手部、头盔代理或大量贴图补空缺。材料试作须有绑定确切模型、材质、代码与桌面/手机真实画面的准入；不成立就停止该素材方案。参考、素材、试片、完整QA及打包首页分别过门。
