# Campo / 素材计划

2026-10-17。以下为参考门后获准的素材验证范围；现已实际执行并因手部工艺/接触损失退回，未批准完整页面或素材模块。原始与转换素材、许可和指纹见 `assets/candidates/campo/sources.json`、`assets/candidates/campo-v2/sources.json`，实际拒绝见 `docs/production/runs/2026-10-17-reference-trial/007-core-rejection.json`。

1. 软木盘：先核对Lusion独立公开的ORYZO-1仓库MIT及具体OBJ的版本和用途。可用公开形态不包含原站纹理/渲染；不抓取站点私有模型。锁定几何SHA、原许可和作者；粗细颗粒、侧壁和光照须另通过真实渲染对照。
2. 手：核对WebXR Input Profiles的通用手资产及MIT，使用无厂商品牌的模型；按真实关节和指甲验证默认与弯曲姿态。正常五指和原创姿态替换六指笑话，不把资产存在视作相同工艺。若模型形态不足，停止这一替代方案。
3. 桌面、切割垫、笔和工具：独立代码几何/绘制的普通物件与表面，按最终桌面/手机的光照、尺度、阴影检查。木质或软木贴图若有缺口，先在ambientCG/Poly Haven查明确CC0的实拍材质；不默认生成新图。
4. 咖啡豆：先查可分发的高质量几何/材质。关键为中央裂缝、体积不规则、烘焙反射和有层次的流场，不能用无裂缝椭球代理。若独立建模，须在素材门单独审查，失败不进入页面。
5. 字体：库存OFL Manrope承担字标和说明，不复用源站商业字体。无脚本/真实渲染失败的四幅静态图由同一已批准场景渲染，不重复申请图像生成。

全部原文件随一份完整可编辑源码包，保留许可与署名。关键模块先形成绑定源码、桌面/手机实图和原生输入的审批；页面生成只调用固定接口，不能另造形态代理。模型/贴图取得后记录逐项SHA、作者、来源、许可、核验日和分发依据。当前计划不能填rightsVerified或replacementCompared为true。
