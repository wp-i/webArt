| 角色 | 最终需要证明的工艺 | 许可与来源边界 |
|---|---|---|
| 冰构空间及有限雪地 | 部件有真实倒角/厚度、不同霜化尺度、内光透射和地形接触。指针抬升后内部仍可信 | 独立空间设计与明确可分发的材料/环境；不取用母版几何、法线、光照图或地形 |
| 两件不同的冻结作品 | 外冰与内件有可辨的纵深、折射、破口及材质区别；原创内件具备具体身份 | 优先核验现有授权库，再限定检索可再分发资产；不将母版品牌对象换名后分发 |
| 冰质开口及过渡 | 断开的表面在观看中连续重组，内外表面与光源关系成立，手机有独立完整构图 | 需独立曲面/材料模块，并绑定真实桌面/手机渲染；普通圆环与噪点不直接准入 |
| 三个独立体积粒子目标 | 全体积而非平面图标，分散/回归及形态交接有控制，静止主体仍精确 | 原创或明确授权的体积采样目标；不复制源企鹅、商标、VDB或采样数组 |
| 字体、标记与有限环境 | 小型等宽标签与物件比例匹配；冰、雪、光具有一致主题 | 本地OFL字体和独立标记；环境/材料逐项记录许可、原始输入与最终SHA，不使用源站音效 |

最终模块先完成有限材料/物件试作。所有几何、纹理、环境、字体和转换步骤须进入素材记录及唯一包通知；许可与视觉准入分别检查。没有同等级替换就停止候选，不用复杂技术或零生成获得审美加分。
