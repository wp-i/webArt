# 本地预览

作品首页：[http://127.0.0.1:4180/](http://127.0.0.1:4180/)。新版 Pace 审阅页：[http://127.0.0.1:4323/](http://127.0.0.1:4323/)，[唯一源码包](http://127.0.0.1:4323/pace-source.zip)。本地进程在电脑重启后需要重新启动。

在仓库目录运行 `powershell -NoProfile -File scripts/start-preview.ps1` 启动首页，追加 `-Profile pace-review` 启动新版审阅页。目录、固定端口及页面身份读取 `webart.previews.json`。已有正确页面时确认健康后退出；没有监听时启动隐藏后台进程，日志与进程收据位于 `.webart/preview-services/`。需要排查时可显式追加 `-Foreground`。首次使用或源码更新后先构建对应项目；端口被其他应用占用时停止，不关闭其他程序。
