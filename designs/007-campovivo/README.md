# Campovivo

An editable one-page culinary-experience demonstration. This is a fictional brand and the generated coastal image is illustrative, not a real workshop location.

## Run

Install Node.js 20.19+ or 22.12+, then run `npm ci` and `npm run dev`. For deployment use `npm run build`; `npm run preview` checks the production build.

## Customize

Edit the title, introduction, practical questions, contact copy and all email links in `index.html`. Replace `public/assets/hero-coast.png` with your own portrait image. Keep the central village/subject visible in desktop and mobile crops. Edit colors, font sizes and crops in `src/styles.css`. Replace CAMPOVIVO with a similarly sized name and check it at 320, 390, 1440 and 2048 pixels.

Native disclosure controls and email links work without JavaScript. No payments, newsletter service or booking backend is included. Replace the example email address before using the page.
