# House of Ivory — Woven spaces

Editable textile/interior studio template. Install with `npm ci`, run with `npm run dev`, build with `npm run build`.

Edit the short text in src/content.json. Vite synchronizes it into the default HTML; main content remains available without JavaScript. Edit layout in src/styles.css, native scroll/index behavior in src/main.js, and images/fonts in public/assets.

Replace the illustrative mail address with your contact address. Images illustrate textile and interior ideas and do not represent commissioned work or staff. Source and license notices are in THIRD_PARTY_NOTICES.md.

Desktop vertical scrolling advances the space panorama. Reduced motion and no-script modes use a native horizontal gallery; material selection supports mouse, focus and tap. No-script mode shows both material views.
