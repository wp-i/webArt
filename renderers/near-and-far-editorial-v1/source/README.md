# Near & Far

安装：npm ci
预览：npm run dev
构建：npm run build

修改 src/content.json 即可更新固定文案；Vite自动同步默认HTML，无脚本仍可读取。布局与交互编辑 src/main.js、src/styles.css，素材在 public/assets。联系链接按实际用途替换；默认页面、触摸、键盘和减少动态均应完整可用。

This is a demonstration portfolio. The three selected works are licensed Pexels photography credited beside each image and in THIRD_PARTY_NOTICES.md. The three coloured photographer portraits depict one original fictional adult made with OpenAI image generation; they do not depict the photographers who made the Pexels works. No client commissions or endorsements are claimed. Replace hello@example.com with your contact address before use.

Without JavaScript, the main navigation points to the visible photographic collection and each work opens its local full-resolution WebP. JavaScript enhances those same works into the continuous detail composition and native viewing tools. Extra-wide portraits use a bounded panel to preserve the full head, camera and holding hands.
